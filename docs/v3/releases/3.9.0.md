# AvenoxBeyin V3.9.0

A new, optional tool: **yakala** (capture). Capture a source with one keystroke wherever you see it (a video, tweet, article, email, PDF, file, or a sentence that comes to mind), and your agent extracts the text and ties the lessons to `knowledge/` notes. If you do not install it, no behavior changes. This release also brings an optional inbox report to doctor, a list of notes linked to a rejected inference, and a state-path fix for vaults synced from another operating system.

## Existing users: update once

In the vault folder on macOS / Linux:

```sh
python3 beyin.py update
```

Windows:

```powershell
py -3 beyin.py update
```

Telling your agent "update my brain" also runs the same command. For a fresh install, download `beyin-v3-3.9.0.zip` and the `.sha256` file next to it; do not use GitHub's Source code archive.

## What's new

### Yakala (capture): throw it into your brain with one keystroke

Install once, in the vault folder: `python3 beyin.py yakala kur` (`py -3` on Windows). Or tell your agent "install the yakala tool".

- **A shortcut in every app:** `Control+Option+B` on Mac, `Ctrl+Alt+B` on Windows. A small window shows what will be saved: the page in the browser (Chrome, Arc, Brave, Edge, Safari on Mac), the file selected in Finder, or the text on the clipboard. If you like, write a one-line "why" and press Enter.
- **Change the shortcut:** `python3 beyin.py yakala kisayol 'cmd+"'`. Character keys are found from the active keyboard layout (on a Turkish Q layout, `"` is the key to the left of 1). On Windows, Ctrl/Alt/Shift plus a letter, digit or F key.
- **Files on Windows:** right-click > Send to > Beyne At ("Throw into the brain").
- **Browser:** an importable "Beyne at" template for Obsidian Web Clipper; pages that require login (Gmail, paid articles) can be captured this way too.
- **Processing:** tell your agent "process the captures". On YouTube, first a chaptered transcript ([Defuddle](https://github.com/kepano/defuddle), pinned version); if that fails, `yt-dlp` subtitles; if there are none, only the audio is downloaded and transcribed with local Whisper, and the audio is deleted. X, Reddit, GitHub and articles are turned into clean text. The raw text stays under `📥 000-Inbox/Yakala/.ham/` and does not mix into search.
- **Privacy:** capture does not go to the network. The network is used only in the processing step and only for the sources you captured. Email, clipboard and file cards are `visibility: private`.
- No extra package is needed. If `npx` (Node), `yt-dlp`, Whisper and `pdftotext` exist, they are used; `beyin.py yakala durum` (status) tells you which ones are found. To remove it, use `beyin.py yakala kaldir` (remove); the cards stay in place.

Details: https://github.com/avenoxai/avenoxbeyin/blob/main/docs/v3/YAKALA.md

### Other

- **Inbox report (#253):** with `preferences --inbox-report on` (off by default), doctor tells you how many notes in the inbox folders have been waiting and for how long; the thresholds are `--inbox-max-items` and `--inbox-max-days`. It does not move or classify notes. Yakala's processed cards do not count as waiting.
- **Doctor lists notes linked to a rejected inference (#252):** when you reject an inference, the current notes that still link to it appear in the doctor output.
- **State path coming from another operating system (#249, #250):** in a synced vault, a `C:\` path written on Windows was mistaken on macOS (or vice versa) for a relative path, and state was opened in the working folder. Now this machine's default state path is used, and reinstalling fixes the foreign path.
- **Lighter startup (#256, #262):** the `beyin.py` CLI is called in the same process without opening a separate Python process; the prompt hook does not load the sync engine and the secret filter for context, and the CLI does not import the engine in commands that need no sync. Behavior and privacy gates are the same.
- **Windows test environment (#257):** System32 was added to the isolated test environment; contributors' tests on Windows now also pass locally.

## Verification

- Before release, 1,050 V3 tests passed; `tests/v3_yakala_test.py` covers the real install, the entry, hook notification, shortcut recipes and Windows shortcut creation. The CI package verifies on Windows, macOS and Linux with Python 3.11 and 3.13.
- Yakala was tried with real sources: YouTube (chaptered transcript), an X post, an article, audio + Whisper for a video without subtitles. The Mac shortcut was triggered with a real listener.
- The Yakala skill is not part of the package; it is written by `kur`: the updater of earlier releases accepts only three startup skill paths.
