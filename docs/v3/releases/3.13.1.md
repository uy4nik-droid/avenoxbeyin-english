# V3.13.1 (English edition)

This is the first release of the English edition, published from
`uy4nik-droid/avenoxbeyin-english`, a fork of
[avenoxai/avenoxbeyin](https://github.com/avenoxai/avenoxbeyin). It carries the same
features as upstream V3.13.0 ([release notes](3.13.0.md)).

## What changed

- Documentation, the install recipe (`beyin.md`), the vault template, the agent skills and
  the text the CLI, the V3 hooks, the local web view and Yakala show are now in English.
  The legacy V2 hook scripts under `template/.claude/hooks/` keep their Turkish messages,
  because the installer recognises an unmodified V2 vault by the hashes of those files.
- Installation and `beyin.py update` use this fork's own releases, so an English install
  stays English when it updates.

## What did not change

- Commands, subcommands, flags, skill names, file and folder names and the note data format
  keep their original names (`beyin.py`, `yakala kur`, `beyin-doktor`, `Kurallar.md`,
  `durum: islendi`, ...). Notes and vaults stay compatible with upstream.
- Turkish search support (stemming, ASCII folding, Turkish trigger words) is still there.

## Moving an existing upstream install to this edition

Download `beyin-v3-3.13.1.zip` from this fork's release page and run
`python3 beyin.py update --package <path to the zip>` in the vault.
