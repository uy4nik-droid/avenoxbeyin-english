# AvenoxBeyin V3.10.0

The Yakala (capture) tool has settled in on all three operating systems: Linux support arrived, on Windows the shortcut works right after install and captures screenshots, and the macOS listener is gone from the Dock. In the core, warm sync got more than twice as fast at 1,500 notes; there are fixes for the `recap` date range, the list of folders excluded from the index, and hangs in the V2 migration.

## Existing users: update once

In the vault folder on macOS / Linux:

```sh
python3 beyin.py update
```

Windows:

```powershell
py -3 beyin.py update
```

Telling your agent "update my brain" also runs the same command. For a fresh install, download `beyin-v3-3.10.0.zip` and the `.sha256` file next to it; do not use GitHub's Source code archive.

**If you installed Yakala with 3.9.0**, run `python3 beyin.py yakala kur` once after updating (`py -3` on Windows). The macOS listener and the Windows shortcuts run from the copy that `kur` writes; the update does not refresh them on its own. Your key is preserved.

## What's new

### Yakala

- **Linux (#276, #278):** `yakala kur` writes the shortcut into the desktop's own settings on KDE Plasma and GNOME (default `Ctrl+Alt+B`). On other desktops it gives you the command to bind. The window shows the link or text on the clipboard, or a file copied from Dolphin/Nautilus; the Wayland clipboard is read with `wl-paste`. If `tkinter` is absent, the question is asked with `kdialog` or `zenity`. Tried on a real KDE Plasma 6 Wayland desktop; GNOME was verified only with unit tests.
- **The shortcut works immediately on Windows (#271):** `kur` now starts a shortcut listener in the background and registers it in the Startup folder; in 3.9.0 the key worked only after the session was reopened. `yakala durum` tells you whether the listener is running, and `kaldir` removes only its own vault's registration. Commands that crashed on the console with `UnicodeEncodeError` because of emoji (cp1254, cp1252) now work; the output is the same on a UTF-8 console.
- **Windows shortcuts preserve Turkish letters and emoji (#271):** the Start menu and Send To shortcuts of 3.9.0 corrupted characters not in the system code page (a vault path containing `📥` was written as `??`). `yakala kur` rewrites the shortcuts correctly.
- **Screenshots on Windows (#284):** an image taken with `Win+Shift+S` is now captured as a card; 3.9.0 saved only the path of a temporary file that was going to be deleted. A screenshot from the last 10 minutes comes ready to be added; an older image or one with an unknown source appears in the window but does not enter the card until it is added with `Tab`.
- **macOS (#273):** the listener does not show up in the Dock as a Python icon; when you say "Quit", launchd restarts it. `yakala durum` shows an installed but stopped listener as "durmus" (stopped).
- **Inbox folder (#272):** in a vault without emoji (`000-Inbox`), a second `📥 000-Inbox` is not created. An inbox that already contains `Yakala/` is used; if there is none, the starter folder; if that is absent too, the single folder whose name is an inbox. Explicit choice: `python3 beyin.py yakala kur --klasor "000-Inbox/Yakala"` (the folder must be inside the vault). Existing cards do not move.
- **The right language for dubbed videos (#283):** on auto-dubbed YouTube videos, the transcript is taken in the spoken language (previously it was one of the dub languages, mostly Arabic). The video card carries the transcript's language in the `dil` field and the subtitle track used in the `altyazi` field; if a transcript in the spoken language could not be obtained, it writes `uyari` (warning). `yt-dlp` is needed for language verification.
- **Helper tool arguments on Windows (#287):** addresses going to helpers that are batch files, such as `npx`, no longer pass through the command interpreter. With addresses containing `&` (most YouTube links), the Defuddle path was cut off and the rest of the address was left to the command interpreter.

### Core

- **Faster warm sync (#251):** unchanged notes are not re-read (a signature made of size, modification times and file identity). Warm sync on 1,500 notes dropped from 223 ms to 92 ms, and with a single note changed from 232 ms to 99 ms (macOS). A signature is trusted only after the same signature has been seen twice, so the first two syncs after an update, install or rollback read all notes. To read without trusting any signature, use `python3 beyin.py sync --full`.
- **Folders excluded from the index (#275):** so that documentation of code repositories embedded in the vault does not outrank your notes, use `python3 beyin.py preferences --index-exclude-dir 3rdparty` (`--index-include-dir` to undo). No folder name is skipped automatically; if `doctor` sees such a tree with upstream docs, it suggests it in a single line together with the command. `notes`, `knowledge`, `tasks` and the companion folder cannot be put on the list. Receipt sources pointing into a folder on the list count as private. This is not a privacy tool: what keeps a note out of the context is `visibility: private`.
- **`recap` date range (#229):** `python3 beyin.py recap --since 2026-10-01 --until 2026-10-07`. When only a date is given, this machine's local calendar day is used (the same day as the `daily/v3/` files); `--until` covers through the end of that day. A full ISO 8601 timestamp must be given with a time zone. It cannot be used together with `--days`.
- **The V2 migration no longer hangs (#270, #285):** an `inflight` record left by a dead V2 flush no longer stops install and `update` if its lock is free and it is older than an hour; the file is not touched, and its path is reported as `orphaned_legacy_state`. A lock folder left from the V2 prompt counter is evaluated by V2's own rule (empty and eight days old). An unreadable V2 state folder is no longer silently passed over; install stops with a clear message. What to do for each case that still stops is in `docs/v3/MIGRATION.md`.
- **Doctor counts knowledge distillation correctly (#279):** besides `knowledge/`, notes under `🧠 500-Knowledge/` and `500-Knowledge/` are also counted, the same set as the Stop reminder. A hand-edited `🧠 500-Knowledge/` note also resets the counter.
- **Antigravity global bridge (#280):** Antigravity sessions opened in a project outside the vault can be connected to the global bridge: add the output of `--harness antigravity --print-config` to `~/.gemini/config/hooks.json`. The format was tried live on Windows with Antigravity CLI 1.2.16. Antigravity sessions inside the vault are now labeled with the name of the first workspace instead of `.agents`.
- **Windows Git Bash (#282):** the whole installed hook command now also runs through Git Bash on every change in Windows CI.

## Rollback notes

- If you go back to 3.9.0, the list of folders excluded from the index is ignored and everything is reindexed.
- On Windows, the Startup registration of the yakala listener (`Beyne At Dinleyici ....lnk`) is not recognized by 3.9.0; delete it by hand.
- If you added the Antigravity global bridge, remove the `beyin-v3-bridge` key in `~/.gemini/config/hooks.json` before going back to 3.9.0.
- The first update from 3.9.0 to this release does not show the note reporting orphaned V2 records (its result is produced by the old updater); the note appears from the next update on.

## Verification

- Before release, 1,329 V3 tests passed on Python 3.11 and 3.14; the 10/10 development and 6/6 holdout semantic scenarios passed. The CI package verifies on Windows, macOS and Linux with Python 3.11 and 3.13.
- The Windows-specific changes (shortcut listener, named mutex and event, shortcut writing, clipboard image, helper tool arguments) were tested in Windows CI with tests running against the real Win32 API. Two Windows defects (character corruption in shortcuts and helper tool arguments) were reproduced in separate measurement runs on a Windows runner before being fixed.
- Not tried on a real desktop: the window taking focus when the key is pressed on Windows and the listener starting at login, the formats the Snipping Tool puts on the clipboard, GNOME. Opening an issue is enough for feedback.
